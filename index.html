How I troubleshoot

        
The steps I follow when an API call or a query misbehaves.

      

      

        
    
          
  1. 
            
    Reproduce it
    
            
    Get the exact request, the input and the error message. If I can make it fail on demand, I can tell when it is fixed.
    
          
    2. 
          
  2. 
            
    Narrow it down
    
            
    Check one layer at a time: the request and its validation, the API logic and exceptions, then the database query and its data.
    
          
    3. 
          
  3. 
            
    Fix and retest
    
            
    Change one thing, then run the same request again. Confirm the fix works and that nearby cases still behave.
    
          
    4. 
          
  4. 
            
    Write it down
    
            
    Record the cause, the fix and how I checked it, so the next person can solve the same issue faster.
